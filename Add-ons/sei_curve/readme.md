## Installation

1. Download [sei_curve (wip).py](<./sei_curve (wip).py>) or [sei_bbonenet.py](<./sei_bbonenet.py>).
1. In Blender, go to `Edit -> Preferences -> Add-ons -> Add-ons Settings -> Install from Disk`.
1. Locate and select the downloaded file.
1. Upon successful installation, the tools will apear in the 3D View toolbar (shortcut: **T**).
